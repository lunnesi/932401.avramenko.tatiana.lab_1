# 932401.avramenko.tatiana.lab_1
 Персональная веб-страница «О себе»

Учебный проект (Вариант 1: Студент-разработчик) — цифровая визитная карточка с информацией о навыках, проектах и формой обратной связи.

Фичи проекта
- Сине-белая цветовая гамма:
    чистый и строгий визуальный стиль на CSS3
  
- Интерактивные списки:
    маркированный список навыков и нумерованный список учебных проектов
  
- Боковая панель (`<aside>`):
    блок с любимыми инструментами разработки (VS Code, Git, Oracle)
  
- Форма связи: 
    поля для ввода имени, email и сообщения
  
- Изолированные ресурсы:
    все медиафайлы хранятся в отдельной папке `assets/`

Структура проекта
index.html       # Главная страница сайта
README.md        # Описание проекта
assets/          # Папка с медиаресурсами (аватар)
