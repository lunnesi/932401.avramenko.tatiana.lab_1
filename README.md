Персональная веб-страница «О себе»

Учебный проект (Вариант 1: Студент-разработчик) — цифровая визитная карточка с информацией о навыках, проектах и формой обратной связи.

Реализовано в ЛР №3 (Вариант 1)

Особенности и стек технологий

- HTML5: Семантическая разметка (`<header>`, `<main>`, `<aside>`, `<section>`, `<article>`, `<figure>`).
- CSS3: 
  - Использование CSS-переменных (`:root`) и современной типографики.
  - Flexbox: Адаптивное меню навигации и карточки витрины проектов.
  - CSS Grid: Адаптивная сетка навыков и галерея скриншотов с квадратными пропорциями (`2×2` на планшетах и ПК).
  - Media Queries: Полная адаптивность под мобильные устройства, планшеты и десктопы.
  - Пройден контроль контрастности WCAG (текст > 4.5:1).
