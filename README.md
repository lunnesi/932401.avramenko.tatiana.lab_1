# 932401.avramenko.tatiana.lab_1
 Персональная веб-страница «О себе»

Учебный проект (Вариант 1: Студент-разработчик) — цифровая визитная карточка с информацией о навыках, проектах и формой обратной связи.

 Реализовано в ЛР №2 (Вариант 1)

Подключение CSS: Внешний style.css, inline-стиль в <header>, внутренний <style> для поля Email.

CSS-переменные (:root): Синий и тёмно-синий цвета, светлый фон.

Позиционирование: static (footer), relative (сетка и карточки), absolute (бейдж «Top skill»).

Интерактивность:

   1.Сетка навыков: увеличение при :hover и уменьшение при :active.

   2.Форма: подсветка рамок при :focus.

   3.Ссылки: стили для :visited и :hover.

Контрастность: Соотношение текста и фона > 4.5:1.
